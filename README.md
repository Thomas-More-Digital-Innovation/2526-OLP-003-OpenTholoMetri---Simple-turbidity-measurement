## System Overview

The OpenTholoMetri is a data logging system designed for turbidity measurement using optical sensors. The system operates in a low-power mode, periodically waking up to take sensor readings, logging the data to an SD card with timestamps, and then returning to sleep.

## CSV Viewer (GitHub Pages)

This repository includes a small, static website that loads and plots the CSV generated by the device. It runs entirely in the browser (no server).

- Site entrypoint: [code/pages/index.html](code/pages/index.html)
- Expected CSV format (from firmware):
	- Headers: `Timestamp,Proximity,Ambient Light,Battery Voltage`
	- Timestamp format: `YYYY-MM-DD HH:MM:SS`

### Use locally

- Open [code/pages/index.html](code/pages/index.html) in a browser.
- Drag & drop a CSV, or use the file picker.

### Deploy on GitHub Pages

- In GitHub: **Settings → Pages**
- Set **Source** to **Deploy from a branch**
- GitHub Pages "Deploy from a branch" supports `/ (root)` or `/docs` only. Since the viewer now lives in `/code/pages`, you can either:
	- move it back to `/docs`, or
	- use a GitHub Action to deploy `code/pages` to a `gh-pages` branch.

### TypeScript source (optional rebuild)

The site ships with a prebuilt JS bundle in `code/pages/assets/app.js`.
If you want to rebuild it from TypeScript:

- `npm install`
- `npm run build`
