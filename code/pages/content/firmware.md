## Download or clone the [repository](https://github.com/Thomas-More-Digital-Innovation/2526-OLP-003-OpenTholoMetri---Simple-turbidity-measurement)

## Install Arduino IDE

See [installation instructions](https://support.arduino.cc/hc/en-us/articles/360019833020-Download-and-install-Arduino-IDE)

## Install M0 board library

See [adafruit installation instructions](https://learn.adafruit.com/adafruit-feather-m0-basic-proto/setup)

## Set measurement values

Set the desired values in [config.h](https://github.com/Thomas-More-Digital-Innovation/2526-OLP-003-OpenTholoMetri---Simple-turbidity-measurement/blob/main/code/main/Config.h), don't forget to save!

## Install firmware

Plug in the board via USB, select the board in the Arduino IDE (COMx) and press the "upload" button (arrow).
