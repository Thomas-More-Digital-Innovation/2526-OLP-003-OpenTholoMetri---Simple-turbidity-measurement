# Materials & Tools

### Mechanical Components

- **Sensor Housing**: 3D printed enclosure (files available in repository)
  - Material: PETG
  - Clear UV resistant Epoxy: for waterproofing the sensor
  
### Tools Required

- Soldering iron and solder
- Wire strippers
- 3D printer (or access to 3D printing)
